# Supabase Configuration

To fix 401 errors related to Row Level Security (RLS), please execute the SQL commands in `rls-policies.sql` in the Supabase SQL Editor.

**Important**: Whenever this file is modified, you must re-execute the SQL commands in the Supabase SQL Editor to apply the changes.

Simply copy and paste the contents of this file into the SQL Editor in your Supabase dashboard and run it.
